# Desarrollo de Aplicaciones Web

## Descripción
Este repositorio está destinado a almacenar y organizar las actividades y proyectos desarrollados durante la asignatura de Desarrollo de Aplicaciones Web, utilizando GitHub como herramienta de control de versiones.

## Información académica
- **Universidad:** Universidad Técnica de Manabí
- **Carrera:** Tecnologías de la Información
- **Asignatura:** Desarrollo de Aplicaciones Web
- **Período académico:** 2026-2
- **Docente:** Ing. Manuel Geovanny Bravo Pico

## Objetivo
Aplicar los conocimientos adquiridos durante la asignatura mediante el desarrollo de proyectos web y el uso de GitHub para gestionar archivos, registrar cambios y organizar las actividades académicas.

## Organización del repositorio
Las actividades se organizarán de acuerdo con las unidades de la asignatura:

- **Unidad 1:** Programación web en el cliente.
- **Unidad 2:** Programación web en el servidor.
- **Unidad 3:** Arquitectura orientada a microservicios web y manejo de estados.
- **Unidad 4:** Sistema de control de versiones.

## Estado del repositorio
Repositorio creado y configurado para almacenar los trabajos de la asignatura.
